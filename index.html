Manage your tool sticks remotely
⚙️ GitHub setup (ek baar)
This is saved only on your phone (localStorage). It is not sent anywhere else.
Agar upar wale PAT ko tpm-devices pe write access nahi hai, to yahan tpm-devices ka token paste karo (wahi jo tool use karta hai). Isse Devices clear/delete mobile se chalega.
Token kaise: GitHub → Settings → Developer settings → Fine-grained tokens → sirf is repo pe Contents: Read and write. Ya classic token with repo scope.
🕹️ Master switch
—
KILL ALL = turn off all copies (except your owner.key one). RESTORE ALL = turn them all back on.
🔐 Whitelist mode
—
Turn ON so only the sticks you have ADDED to the list will run. Any copied/unknown stick auto-deletes itself — you do not need to know its ID. (ADD all your real sticks first!)
🔑 Admin password
—
On all sticks (except owner/master), when the worker clicks SERVER or EMAIL, this password is asked. Leave empty and press OK to remove the password.
🔑 Advanced tools password
—
Locks the tool's advanced features on ALL sticks — including the owner/master: Link Device to Software (VID/PID), Fix Reserved Storage, Account Repair, PC Ready Check, Pre-Ship Check, Install Windows Updates, Sys Repair, NVIDIA Driver, Install Software Pack, Hardware Test, Show Serials. Enter the password once on a PC to unlock for that session. Nobody can open these without the password. Leave empty and press OK to remove the lock.
🚀 Start PCs
Press START — every PC running the Mobile Agent launches the tool from the server and runs its selected Mode (zero-click). The tool does not need to be open; the Agent keeps watch. (Needs the Agent installed + internet on the PCs.)
🧹 GitHub Storage
Roz ke commits se GitHub ki history badhti hai (files chhoti rehti hain, bas purane commits jama hote hain). Ye button poori history ko 1 commit mein squash kar deta hai — aaj ki files safe, purani history saaf. Raat ko ek baar dabao → storage khaali → GitHub kabhi full nahi. (START / tool sab waise ka waisa chalta rahega.)
💾 Sticks
Switch ON = allow  |  OFF = block  |  role dropdown = which features  |  ♔ = owner  |  🔑 = password  |  × = remove
Mode = is stick ko lock karo: AutoPilot ya Sysprep (TRCC). Jo chuna, stick plug karte hi khud usi mode mein chalegi (zero-click, ek cancel countdown ke saath). — (manual) = tool ka apna default. Jab tak yahan se na badlo, stick usi pe chalegi.
Devices
Devices where the tool is present now show here. ● green=tool open now · ●=present, ran recently · ●=not run for a while. Each device shows its 🌎 IP. REVOKE = tool self-destructs on its next online check (device stays in the list as a record). 🗑 DELETE = same self-destruct and removes the device from this list right away (use for a stick/PC you no longer own).
