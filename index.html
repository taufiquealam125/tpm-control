GitHub setup (ek baar)
Ye sab phone pe hi save rahega (localStorage). Kisi aur ko nahi jata.
Token kaise: GitHub → Settings → Developer settings → Fine-grained tokens → sirf is repo pe Contents: Read and write. Ya classic token with repo scope.
Master switch
—
KILL ALL = sabhi copies band (tumhari owner.key wali chhod ke). RESTORE ALL = sab wapas chalu.
Whitelist mode
—
ON karo to sirf wahi sticks chalengi jo tumne list mein ADD ki hain. Koi bhi copy/anjaan stick (worker ne friend ko di) khud DELETE ho jayegi — tumhe uska ID jaanne ki zaroorat nahi. (Pehle apni sabhi asli sticks ADD kar lena!)
Sticks
Switch ON = allow  |  OFF = delete (band)  |  🔑 = password set  |  × = list se hatao
