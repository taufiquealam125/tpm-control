🕹️ Master switch
—
KILL ALL = turn off all copies (except your owner.key one). RESTORE ALL = turn them all back on.
🔐 Whitelist mode
—
Turn ON so only the sticks you have ADDED to the list will run. Any copied/unknown stick auto-deletes itself — you do not need to know its ID. (ADD all your real sticks first!)
🔑 Admin password
—
On all sticks (except owner/master), when the worker clicks SERVER or EMAIL, this password is asked. Leave empty and press OK to remove the password.
🔑 Advanced tools password
—
Locks the tool's advanced features on ALL sticks — including the owner/master: Link Device to Software (VID/PID), Fix Reserved Storage, Account Repair, PC Ready Check, Pre-Ship Check, Install Windows Updates, Sys Repair, NVIDIA Driver, Install Software Pack, Hardware Test, Show Serials. Enter the password once on a PC to unlock for that session. Nobody can open these without the password. Leave empty and press OK to remove the lock.
🌐 Network lock
—
ON = the tool runs only on allowed networks/IPs; on any other network it deletes itself (WIPE) as soon as it is online. Mark your own stick 🌐 Anywhere (in the stick list below) so it runs on every network and is never wiped.
Separate with commas — subnet (192.168.200) or exact IP (192.168.1.55). 192.168.200 and 192.168.8 are always allowed anyway (default). If offline / the check cannot run, it will NOT wipe (safety).
🚀 Start PCs
Press START — every PC running the Mobile Agent launches the tool from the server and runs its selected Mode (zero-click). The tool does not need to be open; the Agent keeps watch. (Needs the Agent installed + internet on the PCs.)

📍 Locate PC (screen flash)
Enter a PC's computer name (or "all") → that PC's screen flashes so you can identify it on the bench. (The tool must be open on that PC.) It flashes once; press Stop to clear it so it does not flash again.
🧹 GitHub Storage
Daily commits grow GitHub's history (files stay small, only old commits pile up). This button squashes the whole history into 1 commit — today's files stay safe, old history cleared. Press it once at night → storage freed → GitHub never fills up. (START / the tool keep working exactly the same.)
💾 Sticks
Switch ON = allow  |  OFF = block  |  ♔ = owner  |  🔑 = password  |  👁 = activity log  |  🌐 = Anywhere (any network)  |  🛡 = Master (never wiped)  |  × = remove
Mode = lock this stick to: AutoPilot or Sysprep (TRCC). Whatever you pick, the stick runs that mode by itself as soon as it is plugged in (zero-click, with a cancel countdown). — (manual) = the tool's own default. Until you change it here, the stick keeps running that.
Devices
